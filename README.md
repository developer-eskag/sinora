# SiNORA – Liposomal Cosmeceutical Website

A premium, science-first frontend prototype for **SiNORA**, a liposomal cosmeceutical skincare brand.

Unlike traditional cosmetic websites that focus primarily on products, this project is designed to educate users about **Liposomal Delivery Technology** through immersive storytelling, interactive animations, and modern UI/UX.

The final website will be integrated into **Shopify Liquid**, while this repository serves as the complete frontend prototype.

---

## Project Vision

The goal is to create a premium digital experience that combines luxury aesthetics with scientific credibility.

The website emphasizes:

- Liposomal Technology
- Product Education
- Ingredient Science
- Interactive User Experience
- Premium Minimal Design

## Design Philosophy

SiNORA is positioned between luxury skincare and pharmaceutical-grade science.

Instead of focusing only on products, the website explains:

- What are Liposomes?
- Why Liposomal Delivery Matters
- How Active Ingredients Reach Deeper Skin Layers
- Benefits over Conventional Cosmetic Products

The visual direction follows a **Luxury Laboratory** approach with minimal layouts, elegant typography, subtle interactions, and smooth animations.
